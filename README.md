# homelab
Enterprise-grade homelab installer — Deploy Nextcloud, Immich, dan Jellyfin dalam satu perintah. Dilengkapi split-storage (SSD untuk user data, local disk untuk app/DB), smart backup berbasis SQL dump, auto-restore, integrasi Telegram, dan full system hardening. Cocok untuk LXC container, VPS, atau bare-metal Debian/Ubuntu.
